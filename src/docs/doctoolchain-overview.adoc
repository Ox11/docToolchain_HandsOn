== docToolchain & AsciiDoc at a Glance

* *Docs-as-code*: AsciiDoc in `src/docs/` → Gradle → `build/`
* *Build*: `./dtcw docker generateHTML | generatePDF | generateDocbook | generateDeck`
* *Config*: `docToolchainConfig.groovy` → `inputFiles`, `imageDirs`
* *Syntax*: `== Section`, `*bold*`, `_italic_`, lists `*` `.`, tables `|===`
* *Blocks*: `NOTE:` `TIP:` `WARNING:`, `include::part.adoc[]`, `image::tux.png[]`
* *Diagrams*: PlantUML built in, Mermaid via Kroki, self-drawn as SVG
* *Publish*: Confluence, microsite, Jira, OpenAPI, Git changelog
