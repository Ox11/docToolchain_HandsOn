# DocToolchain Setup

download the wrapper for the DocToolchain into the project:

```sh
Invoke-WebRequest doctoolchain.org/dtcw.ps1 -Outfile dtcw.ps1
```


```ps
Invoke-WebRequest doctoolchain.org/dtcw.ps1 -Outfile dtcw.ps1
```
